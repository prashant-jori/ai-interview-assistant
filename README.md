# AI Interview Assistant

An AI-powered Interview Preparation Platform built using React, Flask/FastAPI, and Google Gemini AI.

## Features

* User Registration and Login
* PDF Upload and Analysis
* AI-Generated Interview Questions
* Text Answer Evaluation
* Voice Answer Evaluation
* Performance Analysis Dashboard
* Interview Preparation Assistance

## Tech Stack

### Frontend

* React.js
* Vite
* HTML
* CSS
* JavaScript

### Backend

* Python
* Flask / FastAPI
* Google Gemini AI

### Database

* SQLite

## Installation

### Backend

```bash
pip install -r requirements.txt
python main.py
```

### Frontend

```bash
npm install
npm run dev
```

## Project Objective

This project helps students and job seekers prepare for interviews by generating questions from uploaded PDFs, evaluating answers, and providing AI-powered feedback.
